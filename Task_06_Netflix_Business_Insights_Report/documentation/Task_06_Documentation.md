
# Netflix Business Insights Report
## Data Analysis Using Python – Task 6

### 1. Project Overview
This project focuses on analyzing Netflix content data to
identify business trends, content patterns, and useful insights.

The project uses Python-based data analysis and interactive
visualizations to present findings in a professional format.

### 2. Project Objectives
- Perform Exploratory Data Analysis (EDA).
- Analyze Movies and TV Shows distribution.
- Identify top content-producing countries.
- Analyze popular content genres.
- Study release-year trends.
- Examine content rating distribution.
- Generate business insights and recommendations.
- Develop an interactive executive dashboard.

### 3. Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- VS Code

### 8. Business Insights
- Movies represent a larger proportion of the Netflix catalog.
- The United States has the highest country-associated
  content count.
- International Movies is the most frequently listed genre.
- 2018 has the highest number of titles by release year.
- TV-MA is the most common content rating.
