# Task 3 – Country-Wise Netflix Content Analysis

## Internship Details
- **Organization:** Auspify Technologies
- **Internship:** Data Analysis Using Python
- **Task:** Task 3 – Country-Wise Netflix Content Analysis
- **Difficulty:** Medium

## 1. Project Overview
This project analyzes Netflix content availability across different countries using Python. The objective is to identify countries with the highest content availability and understand the distribution of Movies and TV Shows.

## 2. Project Objectives
- Extract and clean country information.
- Calculate country-wise content counts.
- Identify the top 10 countries.
- Compare Movies and TV Shows across countries.
- Generate business insights through data visualization.

## 3. Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 4. Dataset Information
- Dataset: Netflix Movies and TV Shows
- Original Records: 8,790
- Total Columns: 10
- Main Analysis Column: Country

## 5. Data Processing
1. Loaded the cleaned Netflix dataset.
2. Split multiple country names into separate records.
3. Removed extra spaces and empty country values.
4. Used Pandas GroupBy and aggregation operations.
5. Calculated total content, movie count, and TV show count.
6. Generated country-wise rankings.

## 6. Data Visualization
Created the following visualizations:

1. Top 10 Countries by Netflix Content.
2. Movies vs TV Shows by Top 10 Countries.

Libraries used: Matplotlib and Seaborn.

## 7. Business Insights
- Identified the country with the highest Netflix content count.
- Identified the country with the highest movie count.
- Identified the country with the highest TV show count.
- Analyzed country-wise content distribution.
- Generated rankings to support regional content analysis.

Refer to `business_insights_report.txt` for calculated results.

## 8. Project Deliverables
- Python source code
- Cleaned country-wise dataset
- Country-wise summary CSV
- Top 10 country visualization
- Movies vs TV Shows comparison chart
- Business Insights Report

## 9. Conclusion
This project provided practical experience in data cleaning, data aggregation, country-wise ranking, and data visualization using Python.

It helped develop analytical skills and understand how data can be transformed into meaningful business insights.
