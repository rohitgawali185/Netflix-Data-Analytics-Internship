# Task 2 – Netflix Content Type Analysis

## 1. Project Overview
This project analyzes the distribution of Movies and TV Shows available on Netflix using Python.

## 2. Objective
- Analyze Netflix content types.
- Calculate Movies and TV Shows count.
- Compare content proportions.
- Create visualizations.
- Generate business insights.

## 3. Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 4. Dataset Information
- Total Records: 8,790
- Total Columns: 10
- Dataset: Netflix Cleaned Dataset

## 5. Analysis Results

| Content Type | Count | Percentage |
|---|---:|---:|
| Movies | 6,126 | 69.69% |
| TV Shows | 2,664 | 30.31% |
| Total | 8,790 | 100% |

## 6. Visualizations
1. Content Distribution Bar Chart
2. Content Proportion Pie Chart

## 7. Key Business Insights
- Movies represent 69.69% of Netflix content.
- TV Shows represent 30.31%.
- Movies exceed TV Shows by 3,462 titles.
- Movies dominate the analyzed Netflix content library.

## 8. Conclusion
The analysis shows that Movies account for a significantly larger proportion of the Netflix content library than TV Shows.

Python visualization libraries helped present the distribution clearly and effectively.
