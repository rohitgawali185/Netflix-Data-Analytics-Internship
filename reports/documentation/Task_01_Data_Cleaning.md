# Task 01 – Netflix Data Cleaning & Preparation

## 1. Objective
The objective of this task was to inspect, clean, standardize, and prepare the Netflix dataset for further business analysis.

## 2. Tools & Technologies
- Python
- Pandas
- VS Code

## 3. Dataset Overview
- Total Records: 8,790
- Total Columns: 10
- Dataset Format: CSV

## 4. Data Cleaning Activities
1. Imported the dataset using Pandas.
2. Inspected dataset dimensions and column information.
3. Checked missing values.
4. Identified duplicate records.
5. Examined data types and unique values.
6. Analyzed text formatting inconsistencies.
7. Standardized text columns.
8. Standardized content type and country formatting.
9. Exported the cleaned dataset.

## 5. Data Quality Results
- Missing Values: 0
- Duplicate Records: 0
- Original Dataset: 8,790 rows × 10 columns
- Cleaned Dataset: 8,790 rows × 10 columns

## 6. Content Distribution

## 7. Key Findings
- The dataset contains 8,790 records and 10 columns.
- No missing values were identified.

- The cleaned dataset maintained its original dimensions.
