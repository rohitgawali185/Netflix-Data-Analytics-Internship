
# Task 04 – Netflix Release Year Trend Analysis

## 1. Project Overview
This project analyzes Netflix content based on its original release year. The objective is to identify yearly content patterns, growth, decline, and differences between Movies and TV Shows.

## 2. Objectives
- Analyze content releases by year.
- Calculate year-wise Movies and TV Shows.
- Identify growth and decline trends.
- Find the highest content release year.
- Create professional data visualizations.
- Generate business insights.

## 3. Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## 4. Dataset Information
- Dataset: Netflix Cleaned Dataset
- Total Records: 8,790
- Total Columns: 10
- Movies: 6,126
- TV Shows: 2,664
- Release Year Range: 1925–2021

## 5. Data Analysis
The dataset was grouped by release year to calculate:
- Total content
- Movie count
- TV Show count
- Year-over-year content change
- Year-over-year growth percentage

## 6. Key Findings
- 2018 recorded the highest content count with 1,146 titles.
- Content counts declined after 2018 in the available dataset.
- Movies represent the larger share of the dataset.
- TV Shows increased in the later release years.
