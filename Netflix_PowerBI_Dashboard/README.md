# Netflix Power BI Dashboard

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze Netflix's content library. The dashboard provides insights into Movies and TV Shows, content distribution, release trends, ratings, genres, and country-wise content availability.

The objective of this project is to transform Netflix data into meaningful visual insights using Power BI.

## Dashboard Features
- Total Movies and TV Shows analysis
- Content distribution by type
- Movies and TV Shows trends over the years
- Content ratings analysis
- Country-wise content distribution
- Genre/category analysis
- Interactive filters and visualizations

## Key Performance Indicators (KPIs)
- Total Titles
- Total Movies
- Total TV Shows

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analytics

## Business Insights
- Movies represent a significant portion of Netflix's content library.
- TV Shows contribute to the overall diversity of the platform's content.
- Content production and additions vary across different years.
- Netflix offers content across multiple genres and audience rating categories.
- Content availability differs across countries and regions.
